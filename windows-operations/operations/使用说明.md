# 爱绿妈妈后台 · 订单每日巡检

脚本：`songuo_order_inspector.py`（纯标准库，Python 3.8+，不用 pip 装任何东西）

---

## 1. 首次使用（两步）

**第一步**：双击 `config.ini`（用记事本打开），填两行：

```ini
[account]
phone = 138xxxxxxxx
password = 你的登录密码
```

**第二步**：双击 `巡检.bat`（或在当前目录执行 `python songuo_order_inspector.py`）。

> 首次直接运行 `.py` 时，脚本会自动生成 `config.ini` 让你填。

---

## 2. 它巡检什么

对应后台的板块，逐项调接口核对（不是打开网页点按钮，是直接查后台接口，速度快、数据全）：

| 板块 | 接口 | 巡检内容 |
| --- | --- | --- |
| 首页概览 | `POST /admin/homePage/queryOrderCount` | 商城自取待取货、商城快递待发货、积分自取/快递待处理 四个计数 |
| 订单管理 · 商城自取订单 | `POST /admin/order/queryPickUpOrderMessage` | 当日单量、待取货、金额、状态分布 |
| 订单管理 · 商城快递订单 | `POST /admin/order/queryExpressOrderMessage` | 当日单量、待发货、金额、状态分布 |
| 订单管理 · 积分自取订单 | `POST /admin/order/queryPickUpScopeOrderMessage` | 当日单量、待处理 |
| 订单管理 · 积分快递订单 | `POST /admin/order/queryExpressScopeOrderMessage` | 当日单量、待处理 |
| 订单管理 · 退款/退货订单 | `POST /admin/order/queryReturnOrderMessage` | 待处理退款、退款金额 |
| 状态字典 | `GET /admin/ad/queryDicList?dicType=ORDER_STATUS` | 把状态码翻译成中文状态名 |

**每次巡检会检查这 6 类异常**（阈值都在 `config.ini` 里可改）：

1. 待取货 / 待发货 / 积分订单待处理 超过阈值
2. 待处理退款/退货 超过阈值（默认 0 笔，有就报）
3. 最早一笔待处理订单停留超过 N 小时（默认 24 小时，防止隔夜忘处理）
4. 单笔订单金额过大（默认 1000 元，防刷单/错价）
5. 接口访问失败、登录失效
6. 首页计数与订单列表数量差额（提示去后台核对历史单）

## 3. 输出在哪

```
巡检报告\
├── 巡检报告_20261028.md      每日巡检报告（可直接看/发群）
├── 订单明细_20261028.csv     当日订单明细（Excel 打开，含门店/状态/金额/取货码）
├── last_run.json             上次快照，用来算“较上次新增几单”
└── logs\inspection_202610.log 运行日志（接口失败时看这里）
```

同一天重复运行会覆盖当天的报告文件，正常。

退出码：`0` 正常 / `1` 有告警 / `2` 登录或网络失败 / `3` 还没填账号密码。
（以后接监控平台或任务计划时，可以按退出码判断成功与否。）

## 4. 常用命令

```bat
python songuo_order_inspector.py                  :: 巡检今天
python songuo_order_inspector.py --date yesterday  :: 巡检昨天
python songuo_order_inspector.py --date 2026-10-27 :: 巡检指定日期
python songuo_order_inspector.py --peek            :: 打印接口真实返回，用来核字段
python songuo_order_inspector.py --check           :: 只测账号密码能不能登录
python songuo_order_inspector.py --no-report       :: 只看控制台，不写文件
```

## 5. 每天自动跑（Windows 任务计划）

以管理员身份打开 PowerShell，跑一次即可（改成你的路径/时间）：

```powershell
schtasks /create /tn "爱绿妈妈订单巡检" /tr "python \"C:\Users\Elysee\Desktop\订单巡检\songuo_order_inspector.py\"" /sc daily /st 09:30 /f
```

查看 / 删除：

```powershell
schtasks /query /tn "爱绿妈妈订单巡检" /v /fo LIST
schtasks /delete /tn "爱绿妈妈订单巡检" /f
```

## 6. 数据对不上时怎么办

线上版本接口字段偶尔会调整，脚本已经做了字段兼容（状态、时间、金额、订单数组都有多套别名）。
如果某天报告里某个板块显示 0 笔或者状态是「状态1」这种，跑一次：

```bat
python songuo_order_inspector.py --peek
```

它会把每个接口的真实返回字段打印出来，按真实字段名改 `songuo_order_inspector.py` 里 `enrich_orders()` 的取值顺序即可（或者把输出发我，我改）。

## 7. 报错对照

| 现象 | 原因 / 处理 |
| --- | --- |
| `'uo_order_inspector.py' 不是内部或外部命令` | `.bat` 被保存成了 LF 换行 / UTF-8 中文，cmd 解析错行。现在的 `巡检.bat` 已改成纯 ASCII + CRLF；若还报错，直接在命令行跑 `python songuo_order_inspector.py` |
| `登录失败：接口报错（errno=605）` | 手机号或密码不对 |
| `SSL: CERTIFICATE_VERIFY_FAILED` | 公司网络/代理劫持证书，把 `config.ini` 里 `verify_ssl` 改成 `false` |
| 某板块 `0 笔` 或状态显示 `状态1` | 线上字段变了，跑 `--peek` 对照真实返回字段 |
| 控制台中文变成乱码 | 用 Windows Terminal / PowerShell 运行，别用老旧 cmd 字体 |

## 8. 安全提醒

- 密码是**明文**存在本机 `config.ini` 里，这个文件不要发微信、不要传到网盘/代码仓库。
- 想不落盘，可以删掉 `config.ini` 里的密码，改用系统环境变量：`setx SONGUO_PHONE 138xxxxxxxx`、`setx SONGUO_PASSWORD 你的密码`（脚本优先读环境变量）。
- 脚本只做查询（登录、查订单、查字典），**没有任何改单、取消、发货等写操作**，不会动业务数据。
- 巡检频率别调太高（一天 1~3 次足够），避免触发后台的风控/登录次数限制。
